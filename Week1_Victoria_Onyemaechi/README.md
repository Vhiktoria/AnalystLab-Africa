# AnalystLab Africa — Week 1

## ShopSmart Retail Analytics

This project explores sales, customer, product, returns, and inventory data for ShopSmart Retail Group.

### Project Deliverables

- **Understanding the Dataset:** A summary of the datasets, their contents, key fields, and relationships.
- **Excel Analysis:** Data checks, lookups, PivotTables, business insights, and an interactive dashboard.
- **Executive Dashboard:** A visual summary of sales performance, customer activity, and product returns.
- **Business Recommendations:** Practical suggestions based on the findings from the analysis.

### Tools Used

- Microsoft Excel
- PivotTables and charts
- Excel formulas and lookups
